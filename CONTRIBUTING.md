# Contributing

Contributions are welcome if they improve practical business analysis, safer agent design, or clearer pilot scoping.

## Good contributions

- better intake questions;
- new example patterns for specific industries;
- better scoring heuristics;
- agent responsibility templates;
- risk and approval gate improvements;
- client-readable report examples.

## Please avoid

- hype claims about fully autonomous companies;
- fake case studies;
- revenue guarantees;
- vendor-specific lock-in unless clearly labeled;
- unsafe advice for legal, medical, finance, or personal-data workflows.

## Style

Keep language practical. Explain what the agent reads, decides, writes, escalates, and how success is measured.
